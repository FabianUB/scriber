# Scriber Documentation

Scriber is a shadcn-inspired, Streamlit-like PDF builder for Python. Compose pages with containers and components, then render to PDF using a Python DSL.

- Getting Started: install with `uv`, run the example, and explore the API.
- Components: containers (Document, Page, Row, Column, Card) and primitives (Text, Headings, Badge, Button, Separator, Spacer).
